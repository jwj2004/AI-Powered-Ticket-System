# 知答 · 接口契约（v3 · 注册审核版）

> 企业知识库智能问答 Agent。所有接口加 JWT 认证。字段名冻结，改字段必须群里说。

---

## 〇、通用约定

| 项 | 约定 |
|----|------|
| Base URL | `http://127.0.0.1:8000` |
| 认证 | 除 `/api/auth/login`、`/api/auth/register` 外，所有请求头带 `Authorization: Bearer <token>` |
| 字段命名 | snake_case |
| 空值 | JSON `null`，不用空字符串 |
| 错误格式 | `{"detail": "错误说明"}`，HTTP 4xx/5xx |
| 角色 | `admin`（管理员）、`ops`（客服/运维）、`newbie`（新人） |
| 用户状态 | `pending`（待审核）、`active`（已通过）、`rejected`（已拒绝） |
| 同步/异步 | 全部同步 |

## 三、问答（核心）

```
POST /api/chat
Request:
{ "message": "订单导出超时怎么办？", "conversation_id": null }

默认响应 200（SSE，Content-Type: text/event-stream）
前端打字机读 token 事件；不要等整段 JSON 再假动画。

event: meta
data: {"conversation_id":1,"confidence":"high","citations":[{"document_id":1,"title":"订单导出超时排查","chunk_index":3}],"gap_id":null}

event: token
data: {"delta":"订单导出超过5万条"}

event: done
data: {"conversation_id":1,"reply":"订单导出超过5万条...","citations":[{"document_id":1,"title":"订单导出超时排查","chunk_index":3}],"confidence":"high","message_id":101}

兼容：请求头 Accept: application/json 或 body {"stream": false} 时仍返回整段 JSON：
{
  "conversation_id": 1,
  "reply": "订单导出超过5万条...",
  "citations": [
    { "document_id": 1, "title": "订单导出超时排查", "chunk_index": 3 }
  ],
  "confidence": "high",
  "message_id": 101
}

证据不足时 confidence=low，done/JSON 带 gap_id，citations=[]。
```

```
POST /api/feedback
Request:
{ "message_id": 101, "useful": true }
Response 200: { "ok": true }
```

```
GET /api/conversations
Response 200:
[ { "conversation_id": 1, "title": "订单导出超时", "updated_at": "..." } ]
```

```

  { "role": "user", "content": "...", "created_at": "..." },
  { "role": "assistant", "content": "...", "citations": [], "confidence": "high", "message_id": 101 }
```

## 九、冻结检查

- [ ] 注册接口：用户提交后 status=pending，不能直接登录
- [ ] 登录接口：status 不是 active 的返回对应提示
- [ ] 管理员能看 pending 列表、approve/reject、make-admin
- [ ] 所有接口带 JWT（除 register/login）
- [ ] confidence 有 high / medium / low 三个值
- [ ] 列表接口返回 {total, items}
- [ ] 看板返回嵌套结构
