# 知答 · 接口契约（D1 冻结 v2）

> 项目方向已从"工单副驾"调整为"企业知识库问答 Agent"。所有接口加 JWT 认证。字段名冻结，改字段必须群里说。

---

## 〇、通用约定

| 项 | 约定 |
|----|------|
| Base URL | `http://127.0.0.1:8000` |
| 认证 | 除 `/api/auth/login` 外，所有请求头带 `Authorization: Bearer <token>` |
| 字段命名 | snake_case |
| 空值 | JSON `null`，不用空字符串 |
| 错误格式 | `{"detail": "错误说明"}`，HTTP 4xx/5xx |
| 角色 | `admin`（管理员）、`ops`（客服/运维）、`newbie`（新人） |
| 同步/异步 | 全部同步 |

  "message": "订单导出超时怎么办？",

## 九、D1 冻结检查

- [ ] 所有接口带 JWT，除了 /api/auth/login
- [ ] 角色三种：admin / ops / newbie
- [ ] /api/chat 返回 message_id，feedback 和 notification 靠它关联
- [ ] confidence 只有 high / low
- [ ] 空值用 null
- [ ] 会话历史接口支持跨会话记忆
- [ ] FAQ 接口支持管理员从 gap 发布新手指南
- [ ] 管理员能创建用户（POST /api/users）
- [ ] 上传文档时能选空间（GET /api/doc-spaces）
